# aegis-master-kit

`aegis-master-kit` is the organization architecture kit for Aegis.

It is project-independent. It defines how the Master should behave, how the Master should build the top-level organization, and how visibility and responsibility boundaries are enforced.

It does not store project facts, causal truth, task archives, or code.

## Read order

```text
1. master/MASTER_CONSTITUTION.md
2. master/VISIBILITY_BOUNDARY.md
3. master/RESPONSIBILITY_CONTRACT.md
4. master/CLAIM_VERIFICATION_POLICY.md

10. organization/topologies/linear_001_002_003.yaml
```
