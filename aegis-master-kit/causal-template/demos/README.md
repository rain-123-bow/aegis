# Causal Template Demos

- `demo_project_causal_repo/` shows the repo-visible encrypted shell.
- `demo_master_plaintext_payload/` shows the Master-side decrypted logical structure.

The demo plaintext payload must not be copied into a real project repository as plaintext.

Boundary examples:

- `Target OS is Ubuntu 22.04` is rejected as Causal and routed to Knowledge.
- A Debate Agent claim with why/evidence/scope/assumptions is accepted only as a Causal Proposal pending review.
- A Reviewer direct edit to global causal status is rejected as a Global Causal Write.
