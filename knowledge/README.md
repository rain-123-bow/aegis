# Knowledge Store

This directory stores verified static facts and constraints for this sandbox project.

It does not store causal reasoning, task history, or agent conversations.

A knowledge entry may support later causal construction, but it is not a causal conclusion by itself.

## Admission rule

A fact may enter this directory only when it has adequate evidence for the current sandbox scope.

Developer assertions without evidence should be recorded in `archive/` as assertions, not promoted here as verified facts.
