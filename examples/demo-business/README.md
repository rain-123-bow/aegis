# Demo Business

This is a minimal business-instance skeleton.

It exists only to show that a business is composed of code plus three state libraries:

- `code-repo`: implementation surface
- `aegis-archive`: task process and responsibility chain
- `aegis-causal`: causal truth structures
- `aegis-knowledge`: static facts and constraints

This directory is not the organization system. It is a sample target that Aegis may manage.
